Toolkit 1 · Teacher Data Route Selection

Teacher Guide

Choose the route before CORE 1 / Full Part 1. All three routes target the same learning outcomes.

RouteUse when…Teacher preparationLearning status
A · My Journey DataStudents can safely record their own journeys and are comfortable doing so.Provide anonymised Journey Log; prohibit exact addresses.Core route
B · Class Journey DatasetA class dataset is preferable, individual disclosure is uneven, or the teacher wants collaborative analysis.Aggregate records; replace names with IDs before analysis.Equivalent core route
C · Fictional DatasetStudents lack data, have been absent, privacy is a concern, or time is limited.Use the worked dataset in Toolkit 3.Equivalent core route
Teacher decision rule
