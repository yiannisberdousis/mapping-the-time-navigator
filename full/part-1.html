Teacher Guide

Overview

Overview

The Full Pathway begins by building a trustworthy evidence base. Students define the inquiry question, agree on a data dictionary, collect or work with journey records, clean the dataset, calculate baseline statistics and document data-quality decisions. This stage creates the evidence package that every later decision must reference.

Teacher Guide

Expected Student Output

By the end of this part, students should have produced or demonstrated:

  • A class/group data dictionary and privacy-safe journey dataset.
  • Baseline calculations and at least two initial evidence-based observations.
  • A data-quality log documenting missing values, unusual observations, standardisation decisions and limits.
Teacher Guide

Key Teaching Moves / Implementation steps

1. Launch with the inquiry question and a worked fictional example.

2. Co-construct a data dictionary so every variable has a definition and unit.

3. Apply privacy rules before collection.

4. Collect/prepare records.

5. Clean without deleting genuine inconvenient cases.

6. Calculate baseline statistics manually or with transparent spreadsheet formulas.

7. Record two observations and one limitation.

8. Teacher evidence gate: dataset is READY / NEEDS REPAIR before Part 2.

Teacher Guide

🎨 Creativity Opportunity

Students co-design one meaningful contextual variable and a consistent recording method.

Teacher Guide

🔍 Critical Thinking Prompt

What does our dataset make visible, and what remains invisible because of the way we chose to measure journeys?

Teacher Guide

Suggested GenAI Prompt for Students

No GenAI in Part 1. Human reasoning and data-quality decisions create the baseline for later comparison.

Teacher Guide

Dataset readiness gate

READY when: privacy protected; definitions/units consistent; missing values marked; genuine outliers retained and explained; baseline calculations checked; limitations recorded. If not READY, repair it before Part 2.
