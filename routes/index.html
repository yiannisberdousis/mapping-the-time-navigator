Choose the Data Route

How will students obtain the journey data?

Choose the route before CORE 1 / Full Part 1. All three routes target the same learning outcomes.

A

My Journey Data

Students can safely record their own journeys and are comfortable doing so.

Teacher preparation: Provide anonymised Journey Log; prohibit exact addresses.

B

Class Journey Dataset

A class dataset is preferable, individual disclosure is uneven, or the teacher wants collaborative analysis.

Teacher preparation: Aggregate records; replace names with IDs before analysis.

C

Ready-to-use Fictional Dataset

Students lack data, have been absent, privacy is a concern, or time is limited.

Teacher preparation: Use the worked dataset in Toolkit 3.

Teacher decision rule
Never require a learner to disclose where they live, why they travel in a particular way, or any sensitive circumstance in order to participate. Change the data route, not the learning expectation.
