CORE 1: From Journeys to Data

Teacher Guide

Overview

Overview

In this first phase of the project, students act as data investigators by collecting and analysing information about their own journeys and daily mobility patterns. Through systematic observation and recording, students gather authentic real-world data that will serve as the foundation for all subsequent project activities.

Students are encouraged to think critically about how people experience distance, time and movement in different ways. By working initially without AI support, students develop ownership of the data collection process and gain a deeper understanding of how datasets are created before later engaging with AI-assisted analysis.

This phase introduces students to basic statistical concepts while fostering observation skills, data literacy and evidence-based thinking.

Teacher Guide

Expected Student Output

By the end of this part, students should have produced or demonstrated:

  • One usable evidence set created through Route A (personal anonymised journey records), Route B (aggregated class data), or Route C (teacher-provided fictional data). Five records are desirable for personal data, but participation does not depend on supplying personal journeys.
  • A structured, privacy-safe dataset containing the four core variables: Journey ID, approximate distance (km), duration (min) and transport mode. Additional contextual variables are optional extensions.
  • Basic statistical calculations, including mean, media and range, based on the collected data.
  • Initial observations and reflections about patterns identified within their dataset.
Teacher Guide

Key Teaching Moves / Implementation steps

Step 1 – Introduce the Project

Introduce the concept of mobility data and explain the purpose of the project.

Facilitate discussion around questions such as:

How do people experience distance differently?

Does travelling the same distance always take the same amount of time?

What factors influence journey duration?

Present the Fact File template and explain the variables students will be collecting.

Step 2 – Select the Evidence Route and Build the Dataset

Teachers and students use one of three equivalent routes: A) one week of anonymised personal journey records; B) an aggregated class dataset with no identifiable records; or C) the ready-to-use fictional dataset in the Classroom Toolkit. Route C is a full learning route, not a lesser fallback.

Core variables (required):

Journey duration

Distance travelled

Mode of transport

Extension variables (choose only if they serve the inquiry): time of day

Waiting time or number of stops/transfers

Weather, comfort/stress, accessibility or journey purpose (optional)

Teachers should encourage students to collect data consistently and accurately.

Step 3 – Organising the Dataset

Students organise their collected data into a table or spreadsheet.

Teachers should support students in:

Checking data accuracy

Identifying missing values

Standardising units of measurement

Preparing the dataset for analysis

Step 4 – Statistical Analysis

Students calculate:

Mean journey time

Median journey time

Range of journey times

Where appropriate, teachers may introduce additional measures such as mode or simple visual representations.

Step 5 – Initial Reflection

Students discuss their findings and identify emerging patterns.

Teachers should encourage students to justify observations using evidence from their dataset rather than assumptions.

Teacher Guide

🎨 Creativity Opportunity

Students choose one additional variable that could make mobility experience more visible (for example comfort, waiting time, number of changes, perceived effort, accessibility barrier or environmental condition). They must explain what the variable adds to the story and how it can be recorded consistently. Visual coding may be used only if it carries meaning.

Teacher Guide

🔍 Critical Thinking Prompt

Why might two journeys of similar distance take very different amounts of time?

Use evidence, not assumptions. Which measured variable helps explain the difference? Which relevant factor might still be missing? What can and cannot be concluded from one week of observations?

Teacher Guide

Suggested GenAI Prompt for Students

No GenAI in CORE 1.

Students must first experience how data are produced, cleaned, standardised and interpreted. This creates the human baseline against which later AI-supported analysis will be checked.

Teacher Guide

Dataset minimum structure

Dataset minimum structure
Journey ID | Day/time band | Approx. distance (km) | Duration (min) | Mode | Waiting/transfers | Optional contextual variable
Teacher checks before handover: no identifying locations; units are consistent; missing values are marked rather than guessed; unusual values are retained if genuine and noted; each group can explain how every variable was obtained.
Teacher Guide

📌 Teacher Note(s)

Do not “clean away” inconvenient data. A genuine outlier, delay or inaccessible route may be pedagogically important. Distinguish an error from a real mobility experience. If collecting real journeys is inappropriate, use the prepared fictional dataset while preserving the same reasoning process.
